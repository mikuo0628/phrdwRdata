# phrdwRdata: Retrieve pre-built PHSA Datasets

Efficient interface for for retrieving pre-built datasets. An
ease-of-use wrapper that allows robust user defined filtering while
abstracting away backend database connections, queries, complex joins,
and dataset specific conditions.
